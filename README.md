## Содержание репозитория

### 📁 [Link Tracker](./LinkTracker)
Telegram-бот для отслеживания обновлений на веб-сайтах с уведомлениями в Telegram. Написан на **Go** и включает:

- **Telegram Bot** — интерфейс пользователя (команды `/track`, `/untrack`, `/list`)
- **Scrapper сервис** — периодически проверяет обновления ссылок и формирует события
- **AI Agent** — обрабатывает и суммаризирует обновления перед отправкой пользователю
- **Kafka** — асинхронная доставка событий между сервисами
- **PostgreSQL** — хранение пользователей и отслеживаемых ссылок
- **Valkey** — кэширование и ускорение обработки запросов
- Покрыт **unit** и **integration** тестами (включая Kafka и Valkey через Testcontainers)
- Реализованы паттерны отказоустойчивости: **retry**, **timeout**, **circuit breaker**, **rate limiting**, **fallback**, **dead letter queue**

### 📁 [Executor](./Executor)
Библиотека на C++ для выполнения асинхронных задач в пуле потоков. Поддерживает:
- Выполнение задач в нескольких потоках
- Зависимости между задачами
- Запуск по времени или после завершения другой задачи
- Построение цепочек задач, ожидание группы задач, получение результата первой завершившейся задачи и выполнение задач до заданного момента времени
- Отмену задач и обработку ошибок
- Потокобезопасную работу с использованием примитивов синхронизации стандартной библиотеки C++

### 📁 [Raytracer](./Raytracer)
Трассировщик лучей на C++. Программа читает 3D-сцены в формате `.obj` (с материалами `.mtl`), выполняет рендеринг с использованием модели освещения Фонга и поддерживает:
- Отражение и преломление света
- Мягкие тени
- Настраиваемые материалы (Ka, Kd, Ks, Ns, Ni)
- Режимы отладки: глубина, нормали
- Пост-обработка: тонмаппинг, гамма-коррекция

### 📁 [Hunt The Wumpus](./HuntTheWumpusGame)
Консольная текстовая игра — вариация классической "Hunt the Wumpus" на **python**:
- Игрок исследует пещеры (граф-додекаэдр), избегает ловушек (ямы, летучие мыши) и охотится на Вампусов
- Настраиваемые параметры: количество Вампусов, летучих мышей
- Стрельба с поворотом стрелы
- Система ощущений (ветер, шум, запах)
- Рейтинг в звёздах по итогам игры

### 📁 [Алгоритмы](./Algorithms)
Классические алгоритмы и структуры данных на **C++**:
- Умножение полиномов через **FFT**
- **AVL-дерево** (поиск, вставка, lower_bound)
- Поиск **мостов** в графе и **компонент сильной связности** (Косарайю)
- **Выпуклая оболочка** (алгоритм Джарвиса)

- **Sparse Table** для RMQ2 (вторая порядковая статистика)
- **Trie** для поиска пар строк, конкатенация которых — палиндром
