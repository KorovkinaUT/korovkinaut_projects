# Executor

Этот проект представляет собой реализацию многопоточного исполнителя задач на C++. Исполнитель поддерживает асинхронное выполнение задач, управление зависимостями между ними, запуск по событиям и таймерам, а также построение вычислительных графов с использованием примитивов `Future`.

## Реализованный функционал

* **Многопоточный исполнитель задач:**

  * Пул рабочих потоков фиксированного размера
  * Потокобезопасная очередь готовых задач
  * Корректный запуск, остановка и ожидание завершения работы исполнителя
  * Ожидание завершения всех активных задач

* **Асинхронное выполнение задач:**

  * Запуск произвольных пользовательских функций
  * Получение результата через `TaskWithResult`
  * Ожидание завершения задачи и повторный выброс возникших исключений

* **Система зависимостей:**

  * Выполнение задачи только после успешного завершения всех зависимостей
  * Поддержка произвольного графа зависимостей (цепочки, ромбы, fan-in/fan-out)
  * Автоматическая отмена зависимых задач при ошибке или отмене одной из зависимостей
  * Защита от создания циклической зависимости вида "задача зависит сама от себя"

* **Триггеры запуска:**

  * Отложенный запуск по заданному моменту времени
  * Запуск после завершения другой задачи
  * Поддержка нескольких независимых триггеров для одной задачи

* **Композиция асинхронных вычислений:**

  * Создание продолжений с помощью `Then`
  * Ожидание завершения всех задач через `WhenAll`
  * Получение результата первой завершившейся задачи через `WhenAny`
  * Сбор результатов, полученных до заданного дедлайна `WhenAllBeforeDeadline`

* **Обработка ошибок:**

  * Сохранение исключений, возникших при выполнении задачи
  * Передача ошибок вызывающему коду при получении результата
  * Автоматическая отмена зависимых вычислений при возникновении ошибки

* **Потокобезопасность:**

  * Синхронизация доступа к состоянию задач с использованием `std::mutex` и `std::condition_variable`
  * Корректная работа в многопоточном окружении без гонок данных
  * Безопасное взаимодействие рабочих потоков, таймера и пользовательских потоков
